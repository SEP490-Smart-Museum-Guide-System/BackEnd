# Vé vào cửa

1. Dùng danh mục vé riêng qua API và dùng đơn hàng hiện tại để chốt giá, số người và thanh toán.
2. Cấp một vé QR khi đơn vé được thanh toán. Giữ luồng cấp pass cho đơn dịch vụ số.
3. Thêm API đọc vé và xác nhận lượt vào. Khóa đơn trong giao dịch để tuần tự hóa xác nhận và hủy đơn.
4. Thêm migration và tài liệu tích hợp cho FE.
